# Iris Neural Network Classifier

A machine learning project that trains a feedforward neural network using PyTorch to classify Iris flower species.

---

## Project Overview

This project demonstrates the complete workflow of building a neural network for a multiclass classification problem.

The notebook covers:

- Data preprocessing
- Label encoding
- Training/Test split
- Neural network construction
- Model training
- Loss visualization
- Model evaluation
- Predictions on new samples
- Saving and loading trained models

---

## Technologies

- Python
- PyTorch
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Dataset

The project uses the classic **Iris dataset**, containing measurements of Iris flowers from three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

Features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

---

## Neural Network Architecture

The model is a fully connected feedforward neural network implemented in PyTorch.

Workflow:

1. Load dataset
2. Encode labels
3. Split training/testing data
4. Train the neural network
5. Evaluate performance
6. Predict unseen samples
7. Save the trained model
